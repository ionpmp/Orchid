## First run

1. Start `orchid.exe`.
2. Complete or skip the four-step onboarding overlay.
3. Add widgets from the **catalog** (Files, Terminal, Browser, …).
4. `Ctrl+Shift+P` — command palette. `Win+?` — hint mode.

Opening a `.orchid` file from Explorer starts Orchid (or forwards the path
to the running instance). Workspace version **0.1.0**, no tagged release.
